選定根拠:
- drop_002 は長さ約0.188秒で希望の0.08–0.20秒に収まる。
- 主成分は初期約750Hzから上昇し、0.08–0.12秒では約1,030Hz。約0.045秒までに原音エネルギーの99.5%が収まる。
- 既存 pluck_001 は約440Hz間隔の多数の持続倍音が見える。drop_002 は主に単一の上昇する帯域で、弦を弾いたような倍音列を避けられる。
- bong_001 は約234Hzの低い固定音。drop_001 は高域に広がる鋭い成分が多く、drop_003 はほぼ一定音高。明るい水滴のような短い上昇感の候補として drop_002 を選んだ。
- analysis.png は6候補の波形（左）とスペクトログラム（右）。描画範囲は横0.5秒、縦0–8kHz。

変換:
Oggを48kHz/mono/float WAVに復号後、2msフェードイン、12msフェードアウト。
加工後のピークを-6dBFSに正規化し、48kHz/mono/16-bit PCM WAVに変換。
時間長は維持。切り取り、音高変更、フィルタ、音の追加は行っていない。
元Oggはfloat復号で1.0を超えるサンプルがあるため、16bitへの直接変換を避けて正規化した。
完全な条件、SHA-256はprovenance.json。再現スクリプトはprepare_candidate.py。

時間長の注記: 元Oggのコンテナ情報は0.191088秒、FFmpeg復号後のPCMは0.1881875秒（9033サンプル/48kHz）。前後を手作業で切り取らず、この復号された全サンプルを使っています。
