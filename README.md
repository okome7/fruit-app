# おしゃべりきもちのくだものやさん

くだものやさんをテーマにした、ブラウザで遊べるゲームです。
くだものを選び、ドラッグ操作でレジへ運んで遊べます。

## 技術スタック

- Vue 3 / JavaScript / CSS
- Vite
- Vitest / Vue Test Utils / happy-dom / Node.js 標準テストランナー

## 開発環境

Node.js 24.x と npm を使用します。

```sh
npm ci
npm run dev
```

## ビルド

```sh
npm run build
npm run preview
```

## テスト

```sh
npm run test
```
